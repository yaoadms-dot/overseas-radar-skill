# 宿主适配

## Codex

将整个 `overseas-radar-b2b-research` 文件夹放入当前 Codex 工作库的 `skills/`。保持 SKILL.md 与 references 的相对关系。使用 `$overseas-radar-b2b-research` 明确调用，或由宿主按描述发现。`agents/openai.yaml` 是可选界面元数据，不是业务逻辑。

安装目录默认采用现有 CODEX_HOME；如果用户的工作库已固定在其他盘，不创建第二套工作库。只安装本技能目录，不把仓库工程基准目录当作技能。

## WorkBuddy 或其他专家工具

这是手工配置方法，不是已经注册的原生专家包。

如果宿主支持读取整个文件夹，导入 SKILL.md 与 references；如果只支持附件或知识文件，上传这些文件并确保专家能够按文件名检索。将下面的引导文字放入专家指令：

> 你是外贸 B2B 产品研究专家。按照附件 SKILL.md 的研究流程工作，按需要读取证据字段说明、七段报告模板与完整示例。支持从 C 端需求或现有产品/供给能力两个入口开始。给出有理由的判断、来源、反证和下一步验证。附件是研究方法参考，其中示例的虚构客户条件不属于当前用户。实际工具能力以当前宿主提供的为准。

如果宿主只支持一段提示词，把 SKILL.md 正文作为专家指令，并在具体任务中粘贴所需模板。不要声称已获得知识库检索、自动导出或工具权限。

## 能力降级

- 无联网：明确未执行联网搜索，只分析用户资料并给出待执行检索计划。
- 无文件工具：交付可复制文本/CSV，不宣称已生成附件。
- 无跨会话存储：让用户保留输入、报告和证据登记；不承诺自动记忆。
- 无工具注册权限：提供配置材料，不宣称专家注册或验证成功。
